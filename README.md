# The Circle

An educational alpha prototype for managing a rotating savings circle of ten friends in Blanchardstown, Dublin 15.

### ▶ Try the live demo: https://morabaa-1.github.io/the-circle/app.html

**This is a demo.** All members and payments are fictional. No real money is held or moved.

## Pages

| File | What it is |
|---|---|
| `index.html` | Landing page — what a circle member reads before agreeing to try the prototype *(coming next)* |
| `app.html` | The prototype — a single self-contained file (HTML, CSS and JavaScript, no frameworks, sample data inside) |

## Documents

- `PRD.md` — Product Requirements Document, v1.1 (current)
- `PRD-v1.0.md` — the first version, kept to show how the requirements changed

## Run it

Open `app.html` in any browser. No install, no build step, no backend.
Changes you make last until you close the tab; **Reset** returns to the sample data (Month 4 of 10).
